# 🖍️ Sketch Using Python

A creative collection of Python programs that generate sketches and drawings using code!  
This repository contains fun and artistic sketches created with Python libraries such as `turtle` and others.

Whether you’re learning Python graphics or building visual programs, this repo offers visual examples you can run and explore.

---

## 🌟 Features

- Python sketching programs using `turtle` and other drawing tools  
- Creative and visual output  
- Beginner-friendly examples  
- Great for learning graphical programming in Python

---

## 📁 Project Structure

Each sketch program is in its own folder:

```
Sketch_using_Python/
├── sketch1/
│   ├── main.py
│   └── README.md
├── sketch2/
│   ├── main.py
│   └── README.md
└── README.md
```

Each folder contains Python script(s) that draw creative graphics when run.

---

## 🚀 How to Use

### 1️⃣ Clone the Repository

```bash
git clone https://github.com/pranjalvidyarthi/Sketch_using_Python.git
```

### 2️⃣ Navigate to a Sketch Folder

```bash
cd Sketch_using_Python/sketch1
```

### 3️⃣ Run the Sketch Script

Make sure Python is installed, then run:

```bash
python main.py
```

This will open a window and draw the sketch using Python graphics.

---

## 🛠 Requirements

Install any required packages (if used) using:

```bash
pip install -r requirements.txt
```

If only using `turtle`, no additional packages are needed — `turtle` comes built-in with Python.
